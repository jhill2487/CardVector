# Putnam OS v2.5.0 - Integrated Market Intelligence

This release keeps Market Intelligence inside the existing Putnam OS Pricing Workspace.

## Added
- Integrated Market Intelligence button in Pricing Workspace.
- Comparable Validation Engine inside Putnam OS.
- Rejected comparable CSV export with rejection reasons.
- Filters for World Championship/deck, graded/slab, pack, lot, proxy, sealed, and other non-comparable results.
- Market report CSV generated in Completed Jobs.

## Important
- This release does not automatically reprice yet.
- It is intended to validate comparable filtering before auto-repricing is enabled.
- No standalone user-facing prototype launcher is included.
