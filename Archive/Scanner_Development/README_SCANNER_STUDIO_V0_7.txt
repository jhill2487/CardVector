Putnam Scanner Studio v0.7

Adds auto border preview/manual correction workflow shell.

Install:
1. Extract into C:\Users\JaredHill\Personal\PutnamCollectibles
2. Overwrite scanner_server.py and scanner_studio.html
3. Run: python scanner_server.py
4. Open: http://127.0.0.1:8765

Use:
- Drop image or Choose File
- Run Scanner to call current engine
- Inspect warped/name/number/setcode debug links
- Drag green corners and Save Manual Border Label when auto border is bad
