## Purpose

`Docs/Putnam_Standards/PUTNAM_PRINCIPLES.md` defines why the Putnam ecosystem
exists and how major decisions should be filtered.

`Docs/Putnam_Standards/PUTNAM_PLATFORM_STANDARDS.md` defines how the platform
should be built and maintained.

`Docs/AGENTS.md` defines how Codex and future developers should work inside
the repository.

`Docs/PROJECT_STATUS.md` defines today: current versions, active status,
feature lifecycle, and current milestone.

`Docs/ROADMAP.md` defines tomorrow: planned direction and success criteria.

`Docs/CHANGELOG.md` defines yesterday: what changed over time.

If guidance conflicts, follow the higher-level document.
